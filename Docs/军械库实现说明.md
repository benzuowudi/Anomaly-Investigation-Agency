# 军械库（ArmoryView）实现说明

> 2026-11-11 · 对应 `ArmoryView` 界面与 `item.xlsx / equip.xlsx / itemUse.xlsx` 改版

## 1. 界面结构

FairyGUI 包 `Armory` / `ArmoryView`（1920×1080）：

| 节点 | 用途 |
|---|---|
| `com_bg` | Base/CommonBgCom，标题「军械库 / ARMORY」+ 返回 |
| `txt_title` | 左侧标题「材料」 |
| `list_composite` | 材料/蓝图网格（Base/CommonItemCom，flow_hz） |
| `com_item` | 产物预览（CommonItemCom） |
| `list_item` | 4 个合成材料槽（CommonItemCom） |
| `btn_confirm` | 「开始合成」 |

C#：`Game/Armory/View/ArmoryView.cs`（UIWindow），预制体 `Assets/Res/Prefab/ArmoryView.prefab`，
Addressables 地址 `ArmoryView`，并和 `Armory_fui` 一起放在 `World` 组里（避免再建一套 Group Schema）。
入口：指挥室 `com_armory` → `Game.UI.ShowWindow(UIDefine.Armory)`。

## 2. 操作流程

1. 网格显示 `item.type_show == 3` 的材料/蓝图（未持有的灰显）；
2. 点材料加入 4 个槽（再点一次移除），最多 1 张蓝图；
3. 槽里有蓝图时，`com_item` 预览对应装备；
4. 点「开始合成」：
   - `ArmorySystem.Craft` 校验（1 蓝图 + 1~3 材料、仓库数量足够）；
   - 扣材料（每种 1 个）；
   - 产物写入 `ArmoryData`（`armory.json`）。

## 3. 数据与规则

| 文件 | 说明 |
|---|---|
| `Game/Armory/Data/ArmoryData.cs` | 已合成装备背包（`Dictionary<equipId,count>`），存档 `GameMain/Data/armory.json` |
| `Game/Armory/Model/ArmorySystem.cs` | 合成/发放装备的唯一业务入口 |
| `Game/Armory/Model/ArmoryRecipeRule.cs` | 临时配方：蓝图名字去掉「蓝图」= `equip.name`（2000 匕首蓝图 → 5001 匕首，…） |

配方表未配置，所以先按名字匹配；以后加 `armoryRecipe` 表只替换 `ArmoryRecipeRule`。
合成产物暂不在此界面列出（军械库背包留给后续装备穿戴界面），调试菜单可打印：

- `Framework/军械库/发放测试材料`：给测试用蓝图/材料各 5 个；
- `Framework/军械库/打印已拥有装备`。

## 4. 配置表改版

`item.xlsx`、`equip.xlsx`、`itemUse.xlsx` 的字段变了，已重新生成并同步：

- `ItemData`：`ID/icon/name/type_show/quality/isSell(bool)/sellPrice(string)/use_type(List<int>)`
- `EquipData`：新增 `quality/useRoleATK/atkRange/atkType/magazine/atkInterval`，移除 `specialFlag/equip_set/weight/effect`
- 新增枚举 `GameType.ATKRange`、`GameType.ATKType`
- `Assets/StreamingAssets/Data/gamedata_item_item.json`、`gamedata_item_equip.json` 已更新

连带调整：

- `InventoryData / InventorySystem`（原 Warehouse）：重量临时按「每件重量 1」计算，过滤改为按 `TypeShow`；
- `RoleSystem.BuildSnapshot`：不再读装备 `Weight/Effect/EquipSet`（新表没有这些字段，套装效果暂时不参与计算）。

> 注意：`DataTable/__tables__.xlsx` 与 `__enums__.xlsx` 目前第一行多了一行「列1…列13」标题，
> Luban 要求 A1 以 `##` 开头；现在这份生成结果是先从去掉该行、并给枚举表 `*items` 表头做合并后的副本生成的。
> 以后改表前需要把这两张表的第一行删掉（或直接修好原表），否则 `Framework/配置表导入` 会报「不包含有效的单元薄」。

## 5. 装备图标

`equip.xlsx` 的 `icon` 列已填 `ui_equip_fist / knife / gun / shield / eye / flail`。

- 原图在 `UIProject/assets/CommonUI/Texture/equip/`，已复制到 `Assets/Res/Icon/Equip/` 并登记 Addressables（地址就是 `ui_equip_*`，放在 World 组）；
- `CommonItemCom.ShowIcon`：`ui_equip_*` 先用 `Game.Res.LoadAsset<Texture2D>` 加载成 `NTexture` 塞给 `load_icon`；其它技能/天赋图标仍走 FairyGUI 的 `CommonUI` 包；
- `RoleCardCom / RoleBattleCom / BattleSettingRoleCom` 的装备格改为传原始 `icon`，不再提前 `ResolveIconUrl`。

> 如果以后把装备图也发布进 FairyGUI 的 `CommonUI` 包，可以把 `ShowIcon` 里的 Texture2D 分支去掉，统一走 `ui://CommonUI/...`。
