## 配置表流程（Luban）

1. 把新的 `.xlsx` 放进 `DataTable/`；
2. 在 `DataTable/__tables__.xlsx` 里登记：配置表名、JSON 文件名、类名三者对应；
3. Unity 里执行编辑器菜单 `Framework/配置表导入`（`Assets/Editor/LuBanTool.cs`），生成 C# 行类与 JSON；
4. 业务里通过 `Game.Data` 按表名拿到行数据。

命令行方式见 `Tools/LuBan`，参数顺序注意 `-c` 缓存参数要放在 `-j cfg` 之前。

## UI 制作流程

1. 在 FairyGUI 编辑器（工程 `UIProject/`）里做界面或组件；
2. 发布，产物覆盖 `Assets/Res/UI/*_fui.bytes` 与图集；
3. 用 `Framework/FairyGUI/注册 UI 包到 Addressables` 更新资源注册；
4. 写对应的 `UIWindow`（界面）或 `GComponent`（组件）脚本，并在 `<包名>Data.Init()` 里用
   `UIObjectFactory.SetPackageItemExtension("ui://<运行包名>/<组件名>", typeof(<类名>))` 注册。

> URL 前缀必须用运行时包名（即 `Assets/Res/UI/<包名>_fui.bytes` 的文件名），不要照抄 C# 类名。

## 资源与加载

- 所有 UI 资源都已打进 Addressables，加载界面前要先加载对应包；
- 场景里按需通过 `Operate` 加载 `GameOperate`：新增一个操作需要创建同名空对象并做成预制体打包；
  同一时刻最多存在 1 个 `GameOperate`，加载新的会卸载旧的。

## 系统开发规范

新系统按 `Model`（`ModelBase`）+ `Data`（`SystemDataBase`）+ `Event` 结构制作，并分别在
`DataManager` / `ModelManager` 里注册一次。完整规范见 [系统制作规范.md](系统制作规范.md)。
