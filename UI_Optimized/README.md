# 基地终端 · UI 优化

## 成果

- `UI_Optimized.png` — 1581 × 892 最终效果图
- `UI_Optimized_2x.png` — 3162 × 1784 高清版
- `index.html` — 可直接修改文案和数值的 UI 源文件
- `original.png` — 原图，供对比

## 设计方向

深色战术 HUD：用同一套深蓝玻璃材质承载所有功能，保留角色为画面焦点。  
原来白色、橙色、蓝色、青色的多种卡片，统一为「主面板 + 信息卡 + 主行动卡」三级层级。

## 统一规则

### 布局
- 画布：1581 × 892，安全边距 24px
- 右侧主面板：x 928，宽 630，圆角 28
- 全局间距：8px 基准；卡片间距 15/16px
- 内部卡片圆角：18px；顶栏/底栏圆角：22px

### 色彩
| 用途 | 色值 |
| --- | --- |
| 主背景 / 面板 | `#050E18` → `#0B1824` |
| 主文字 | `#F2F8FB` |
| 次级文字 | `#B0C0C9` |
| 弱文字 | `#8497A2` |
| 信息强调 | `#7CE3E6` / `#45CCD5` |
| 行动/奖励强调 | `#FFB65D` / `#F28A35` |
| 在线状态 | `#7EE2AF` |

### 字体
- 中文：MiSans，回退 Microsoft YaHei UI
- 数字 / 英文标签：DIN Next LT Pro，大写标签增加字距
- 数字层级：78 / 2,430 / 18,000 / 4/5 / 23/24 均使用等宽数字

### 图标
- 统一 24 × 24 线性图标，1.7px 描边，圆角端点
- 不再混用：实心图标、贴纸图标、白色块面图标
- 图标语义固定：床=宿舍、双人=同伴、立方体=仓库、提袋=商店、准星=作战

## 还原说明

`index.html` 引用了同目录的 `background.png`、`avatar.png`、`lottery_art.png`。  
页面按 1581 × 892 的 CSS 视口绘制，可直接在浏览器中打开预览。  
重新截图时建议使用 Edge/Chrome headless，并设置 `--window-size=1605,984` 与 `--force-device-scale-factor=1`（该本机窗口会额外占用 24×92 像素），再裁切顶部 1581 × 892 区域。
